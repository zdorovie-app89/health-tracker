Здоровье

Сон, вода, питание, тренировки, вес. Работает офлайн, данные хранятся только на телефоне.

📱 Android

Скачать приложение (APK, 2,5 МБ)
  1. Открой скачанный файл Zdorovie.apk (в «Загрузках» или в Telegram).
  2. Android спросит про установку из неизвестного источника — нажми «Настройки» и разреши для браузера или Telegram (один раз).
  3. Нажми «Установить». Приложение обновляется само вместе с сайтом.

Нужен Chrome (он есть почти на всех телефонах). Если сайт уже открывал в Chrome — записи будут те же.

🍏 iPhone

  1. Открой сайт приложения именно в Safari.
  2. Нажми Поделиться (квадрат со стрелкой) → «На экран „Домой“» → «Добавить».

В App Store приложения нет — на iPhone оно ставится с сайта. Открывай его значком с экрана «Домой»: так Safari не удалит данные.

💻 Компьютер

Открой сайт в Chrome или Edge и нажми значок установки в адресной строке (или меню ⋮ → «Установить „Здоровье“»). Приложение появится в меню «Пуск» и работает без интернета.
